# Step 1: What you need

Before installing, check you have these. Don't worry if you don't have the software yet; the next pages walk you through installing each piece.

## Checklist

- [ ] **A computer** running macOS, Windows 10/11 or Linux.
- [ ] **A Claude account** that includes Claude Code, such as a Claude Pro or Max plan or an Anthropic API account. See [claude.com/pricing](https://claude.com/pricing).
- [ ] **An internet connection.** Stock prices are downloaded live.
- [ ] **About 20 minutes.**

You do **not** need:

- an account with any stock data provider (data comes free from Yahoo Finance)
- a brokerage account
- any coding knowledge

## The four pieces you'll install

Think of it like setting up a kitchen:

| Piece | What it is | Kitchen version |
|---|---|---|
| **Claude Code** | The AI assistant you talk to | The chef |
| **Node.js** | Lets you run the one-line install command (`npx`) | The delivery van that brings the recipe |
| **uv** | Runs the small Python programs that fetch stock data | The oven |
| **Stock Analyst skill** | The recipe book that teaches Claude how to analyse stocks | The recipe book |

## A word about the "terminal"

Some steps ask you to type commands into a **terminal**. It's just a window where you type instructions instead of clicking.

- **Mac:** press <kbd>⌘ Command</kbd> + <kbd>Space</kbd>, type **Terminal**, press <kbd>Enter</kbd>.
- **Windows:** press the <kbd>⊞ Windows</kbd> key, type **PowerShell**, press <kbd>Enter</kbd>.
- **Linux:** press <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>T</kbd>.

To run a command: **copy** it from this guide (each code box has a copy button in its top-right corner), **paste** it into the terminal, and press <kbd>Enter</kbd>.

:::tip
If you see a lot of text scroll past, that's normal. What matters is that there's no message containing the word **error** at the end.
:::
